# 手動確認 — pi-request-command

自動テストの対象外の確認項目と手順です。変更時は実機で確認します。

## 手動確認項目

- 選択ダイアログに、複数行のコマンドと理由が崩れずに出ること（タイトルの改行）。
- 「出力を貼って完了」で、複数行の出力を貼り付けてそのまま送れること。
- Esc で選択を閉じたとき、モデルに「拒否」ではなく失敗が返ること。
- Esc でエディタを閉じたとき、同様に失敗が返ること。
- モデルが実行済みと報告された後に、読み取り専用のコマンドで状態を確かめる流れになること。
- `pi -p`（print モード）でツールを呼ばせたとき、ダイアログが出ず失敗すること。

## 手順

1. このリポジトリを `pi` の拡張として読み込む（`pi --extension ./src/index.ts`）。
2. モデルに `sudo` を含むコマンドを依頼させる（例: 「nginx の設定を反映してほしい」）。
3. 上の各項目を確認し、結果を作業メモに残す。
