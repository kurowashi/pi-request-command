# pi-request-command

エージェントが sudo などの権限を必要とするコマンドを、あなたが自分の端末で実行するための Pi 拡張です。エージェントは sudo もパスワードも持ちません。コマンドを実行するのはあなたです。

## 仕組み

エージェントが `request_user_command` を呼ぶと、画面にコマンドと理由が出ます。あなたは次のどれかを選びます。

| 選択 | エージェントへ返る内容 |
|---|---|
| 実行した | 実行したという報告。pi は実行していないので、結果は確認できない |
| 拒否 | 拒否したという報告。エージェントは効果があったと仮定しない |
| 出力を貼って完了 | 貼り付けた出力。上限（50 KiB）を超えた分は切られる |

Esc で閉じると、拒否ではなく失敗として扱われます。

## インストール

```bash
pi install <このリポジトリの URL>
```

## 使い方

エージェントに権限が必要な作業を頼むと、エージェントが依頼を出します。依頼が出たら、表示されたコマンドを自分の端末で実行し、その結果を選びます。

「出力を貼って完了」を選ぶときは、出力に秘密情報（パスワード、トークン）が含まれていないか確認してください。貼った内容はエージェントのコンテキストに入ります。

非対話モード（`pi -p` や JSON モード）では、依頼を表示できないため失敗します。

## 制限

- 実行の成否は pi から確認できません。
- 貼り付けた出力の秘密情報は自動で隠しません。
- 出力は 50 KiB までです。
- 依頼の内容を検証しません。表示されたコマンドが安全かは、あなたが判断してください。
